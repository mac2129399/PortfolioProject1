Pharma Insights 2025 - Tableau & SQL Project
This is the first Tableau dashboard I've ever created and my first project as a student building an analytics portfolio. I used a Kaggle dataset focused on global pharma trends for 2025 and explored sponsor company performance across several key areas. 

Tools Used 
1. Excel - data cleaning
2. SQL - exploratory analysis
3. Tableau - dashboard design

I taught myself Tableau this summer through tutorials and examples from other creators on LinkedIn, and this project helped me apply what I've been learning.

Key Insights
- Innovation vs. Revenue
- Peak Sales Potential vs. Company Revenue
- Therapy Area Dominance
- Pipeline Size vs. Approvals
- Revenue vs. Approval Productivity
- Company Strategy Profiles

I included interactive elements like sponsor filters, but I uploaded a screenshot version since I don't have Tableau Public yet.

Why This Project Matters
I work directly with medications that impact patients every day, and analyzing this data helped me understand the bigger picture behind my work. As a student still learning, I welcome any feedback to help me improve.
