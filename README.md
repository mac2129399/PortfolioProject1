Pharma Insights 2025 - Tableau & MSSQL Project

Overview: This is the first Tableau dashboard and my first project as a student building an analytics portfolio. I used a Kaggle dataset focused on global pharma trends for 2025 and explored sponsor company performance across several key areas. 

Tools Used 
1. Excel - data cleaning
2. MSSQL - exploratory analysis
3. Tableau - dashboard design

Key Insights
- Innovation vs. Revenue
- Peak Sales Potential vs. Company Revenue
- Therapy Area Dominance
- Pipeline Size vs. Approvals
- Revenue vs. Approval Productivity
- Company Strategy Profiles


Why This Project Matters
I work directly with medications that impact patients every day, and analyzing this data helped me understand the bigger picture behind my work. As a student still learning, I welcome any feedback to help me improve.
